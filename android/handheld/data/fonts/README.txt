自定义字体使用说明
====================

把你想用的字体文件复制到这里，并改名为 custom.ttf（.otf 也可以，改后缀为 .ttf 即可）：

    data/fonts/custom.ttf

重新启动游戏，字体就会自动换成这个字体（英文数字 + 中文一起换）。

- 删除 custom.ttf（或改回别的名字），游戏恢复默认字体。
- 只支持 ttf / otf 格式。不支持 ttc（字体集合）和 woff。
- 字体文件加载失败时自动回退默认字体，不会崩溃。

注意：游戏的字是 8x8 像素小字（英文）和 12px（中文），
太花哨或太细的字体在小字号下可能看不清，建议用笔画清晰的字体。
